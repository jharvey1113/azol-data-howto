# How the data gets in (AZ Online Learning Hub)

An animated walkthrough of the daily data drop behind the
[AZ Online Learning Hub demo](https://jharvey1113.github.io/az-online-learning-hub/):

1. Download **Manage Enrollments** from the Edgenuity Educator site
2. Download **Manage Students**
3. Drop both CSVs in the shared Drive folder **1. Drop**
4. The Apps Script pipeline scores every course and archives the files
5. The hub shows the new numbers

**Live:** https://jharvey1113.github.io/az-online-learning-hub/ is the hub; this walkthrough is at
https://jharvey1113.github.io/azol-data-howto/

The Educator, Drive and Sheets screens are simplified mock-ups, not screenshots, and
menu names may differ slightly from your Edgenuity account. All data is fictional.
